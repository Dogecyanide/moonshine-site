Installing

Wii (console)

  1. Download a Launcher ZIP.
  2. Copy its apps folder to the root of your SD card, so the launcher is at /apps/moonshine_launcher/boot.dol.
  3. Start it from the Homebrew Channel and pick JP, US or PAL Sunshine from SD, USB or a real disc.

Updating? Replace the app files and use the launcher and mod files from the same ZIP. If you still have apps/susamune_launcher, rename it to apps/moonshine_launcher first. Your settings, records, ghosts and states live in /Moonshine data.

Dolphin (emulator)

  1. Download a Dolphin ZIP.
  2. Apply the matching BPS patch to your own clean ISO with a BPS patcher such as Floating IPS. The patch verifies the source image first.
  3. Put a memory card in slot B so your settings persist.
  4. For goop to save and load correctly with savestates, set Graphics → Hacks → Texture Cache Accuracy to Safe.

SD state and TAS file menus need the Wii launcher; Dolphin has three memory slots.

We strongly advise against running Moonshine with Gecko codes enabled. They will either break Moonshine's features or be broken by them. GameCube hardware is not supported.

What's inside

  • Savestates with three compressed slots, plus named SD states on Wii.
  • Frame advance, free camera and TAS projects.
  • Practice codes built in: timer, metadata, input display, level select, warp wheel and more.
  • IL system with per-level PBs, a PB fanfare and Any% plaza segments. It doubles as a warp list.
  • Ghosts to race against.
  • Nearly everything is configurable, from button binds to the text, position, colour and size of HUD elements.
